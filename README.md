# AIWP_Connect4Project
Repo for the aiwp project - Project title: Generalisation of connect 4

# Initial Setup :

  mkdir name && cd name 
  
  python3 -m venv venv 
  
  source venv/bin/activate 
  
  pip install streamlit 

# Activating streamlit :

  in your folder with ui_main.py run: 

  streamlit run ui_main.py
